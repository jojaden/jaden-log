# SVG 그림 (다크)

그림은 개념을 말로 설명하기 전에 먼저 보여 주는 자리다. 한 문단을 대신해야 하고, 같은 내용을 글과 그림으로 두 번 하지 않는다. 측정값 비교는 SVG 막대로 그리지 않고 `<Bars>`나 `<Stats>`로 보여 준다.

## 좁은 화면에서도 읽히게: 칸은 % 폭, 글자는 px 고정

`viewBox`로 그림 전체를 축소하면 폭 390에서 글자가 8~9px로 작아진다. 사용자가 "작아서 안 보인다"고 여러 번 지적한 부분이다. 그래서 아래 방식으로 그린다.

```html
<svg width="640" height="500" style="height:500px" role="img" aria-label="…" xmlns="http://www.w3.org/2000/svg" font-family="Pretendard Variable, sans-serif">
  <text x="0%" y="17" fill="#F5F5F7" font-size="15" font-weight="700">그림 제목</text>
  <svg x="0%" y="34" width="100%" height="128" overflow="visible">
    <rect width="100%" height="100%" rx="12" fill="rgba(255,255,255,.05)" stroke="rgba(255,255,255,.16)"/>
    <text x="18" y="28" fill="#F5F5F7" font-size="15" font-weight="700">카드 제목</text>
    <text x="95%" y="28" text-anchor="end" fill="#64D2FF" font-size="14.5" font-weight="700">오른쪽 값</text>
  </svg>
</svg>
```

- 바깥 SVG는 `width="640"`, 높이는 `height`와 `style="height:…px"` 둘 다 고정한다. `viewBox`는 쓰지 않는다.
- 카드는 중첩 `<svg x="…%" width="…%" overflow="visible">` 안에 `rect width="100%"`를 깔아 만든다. 폭이 줄면 카드만 좁아지고 글자 크기는 그대로다.
- 왼쪽 글자는 px로(`x="18"`), 오른쪽 값은 `x="95%" text-anchor="end"`로 붙인다.
- 카드는 위아래로 쌓는다. 가로로 나란히 둔 카드는 390 폭에서 글자가 넘친다.
- 글자 크기:
  - 카드 제목: 15px 굵게
  - 본문: 13.5~14.5px
  - 보조 글자: 13px. 13px 아래로는 내리지 않는다
  - 그림 안 코드: `font-family="JetBrains Mono, SF Mono, ui-monospace, Menlo, monospace"`
- 배경 사각형을 깔지 않는다. `<Figure>`가 어두운 유리 상자를 준다.
- `role="img"`, `aria-label`, `xmlns`는 꼭 넣는다.
- 홈 표지로 쓰일 수 있으니 위쪽 절반에 핵심을 둔다.

## 카드 크기 (사용자 지적 모음)

- 작고 빽빽한 카드를 만들지 않는다. 여백을 넉넉히 두고 글자는 위 크기를 지킨다.
- 바깥 카드에 비해 안쪽 카드가 작아 보이면 양옆으로 늘려 바깥 폭에 맞춘다. 크기만 키우는 걸로는 해결되지 않는다.
- 넓어진 카드에서 글자가 왼쪽에만 몰려 있으면 어색하다. 그럴 땐 값을 오른쪽에 붙이거나, 카드를 좁혀 가운데에 둔다(예: 결정을 내린 쪽 카드 두 개를 본문 폭보다 좁게 가운데로).
- 원문자 ①~⑤는 SVG에서 아주 작게 그려진다. 동그라미 안에 일반 숫자를 쓴다(`circle` + `text` "1").

## 팔레트

`scripts/svg.py`에 같은 값이 상수로 들어 있다.

| 역할 | 값 |
| --- | --- |
| 제목 글자 | `#F5F5F7` |
| 보조 글자 | `#A1A1A6` |
| 흐린 글자, 화살표, 라벨 | `#86868B` |
| 중립 카드 | 채움 `rgba(255,255,255,.05)`, 테두리 `rgba(255,255,255,.16)` |
| 강조 카드 | 글의 카테고리 색을 쓴다. 채움은 그 색 `.10`, 테두리 `.55`, 글자는 강조 색 |
| 카테고리 색 | Go `100,210,255` / `#64D2FF`, AI `191,90,242` / `#DA8FFF`, Infra `48,209,88` / `#30D158`, Database `255,159,10` / `#FFB340` |
| 경고, 주의 | `#FFB340`, 채움 `rgba(255,159,10,.10)`, 테두리 `rgba(255,159,10,.5)` |
| 실패, 단점 | 글자 `#FF8A80`, 채움 `rgba(255,69,58,.10)`, 테두리 `rgba(255,69,58,.45)` |
| 성공, 장점 | 글자 `#30D158`, 채움 `rgba(48,209,88,.08)`, 테두리 `rgba(48,209,88,.45)` |
| 화살표 | `stroke="#86868B" stroke-width="1.4"`, marker 채움 `#86868B` |
| 구분선 | `rgba(255,255,255,.1)` |

- 한 그림의 강조색은 한 가지다. 나머지는 중립 회색조로 둔다.
- 티스토리 때 흰 바탕에 그린 그림(`#1d1d1f` 글자, 흰 카드)은 이 표대로 바꾼다.

## MDX 안에서 깨지는 것

- 글자 속 `{` `}`는 `&#123;` `&#125;`로, `<`는 `&lt;`로 바꾼다(예: `&lt;-ctx.Done()`).
- `aria-label`에 `"`를 넣지 않는다.
- 한 글에 SVG가 여럿이면 `marker id`와 `gradient id`를 그림마다 다르게 붙인다(`ts-a`, `fl-a` …). 겹치면 엉뚱한 화살표가 나온다.

## 차례 효과: 과정과 결정을 움직임으로

과정이나 비교로 결론을 내는 그림은 정적인 그림으로 끝내지 않는다. 사용자가 "이전에 말했던 게이지가 차거나 순서대로 나오는 효과를 왜 안 넣었냐"고 물은 적이 있다.

- `class="fx-in"`이 붙은 요소는 그림이 화면에 들어온 뒤 `--d`만큼 기다렸다가 `--t` 동안 나타난다. 기본 `--t`는 .5s다.
- 들어올 때만 움직이고, 화면에서 벗어나면 바로 처음 상태로 돌아간다. 동작 줄이기 설정이나 JS가 꺼진 환경에서는 처음부터 다 보인다.

```html
<g class="fx-in" style="--d:0.10s"><svg … >선택지 카드</svg></g>
<g class="fx-in" style="--d:1.30s;--t:0.9s"><rect … fill="rgba(10,10,12,.62)"/><text …>기각</text></g>
```

- 예(/19 선택지 다섯 개): 카드는 0.1초부터 0.15초 간격으로 빨리 나온다. 기각은 1.3초부터 0.9초 간격으로, 0.9초에 걸쳐 천천히 덮인다. 고른 카드는 마지막에 강조된다.
  - 사용자 요청이 "처음 나타나는 건 빠르게, 기각으로 가려지는 건 천천히"였다.
- 단계마다 줄어드는 양을 보여 줄 때는 `<Bars shrink>`를 쓴다(/15 시간 예산).
  - 막대는 왼쪽 기준으로 채우고 오른쪽이 비게 둔다.
  - 단계 k에서 k번째 아래 줄들이 함께 같은 값으로 깎인다.

## 시간에 따라 변하는 증상

배포 직후 튀는 지연, 서서히 차오르는 메모리처럼 시간 축이 핵심인 증상은 SVG 선 그래프로 그린다. 인기 장애 회고 글은 지표 그래프를 20장 넘게 쓰기도 했다(카카오페이, 인프랩).

- 축은 하나만 둔다. 계열은 둘까지 쓰고, 둘이면 `#2997FF` + `#FF9F0A`로 그린다.
- 사건 시점(배포, 설정 변경)은 세로 점선 하나로 표시하고, 선 위에 직접 라벨을 단다. 범례만 따로 두지 않는다.
- 실제 값을 옮겨 그린다. 모양만 비슷하게 지어낸 그래프는 그리지 않는다. 값이 없으면 그래프 대신 로그나 수치 표를 쓴다.
- 대시보드 스크린샷이 있으면 다시 그리는 편이 낫다. 다크 팔레트와 좁은 화면 배치를 지킬 수 있기 때문이다.

## 단계를 넘겨 보는 그림

알고리즘이나 과정은 한 장씩 넘겨 보는 그림으로 보여 줄 수 있다(Go 블로그 Green Tea GC). `<Carousel>` 안에 `<Slide title="1. …">`마다 그림 하나를 넣는다. 장마다 바뀌는 곳 하나만 강조색으로 칠한다.

## 만드는 방법과 확인

- 스크래치패드에 생성기 `p<id>.py`를 만든다.
  - 첫 줄을 `from svg import *`로 쓰고, `sys.path`에 `.claude/skills/jaden-log-post/scripts`를 넣는다.
  - 한국어·영어 문구를 사전으로 나눠 같은 함수로 두 그림을 뽑는다.
- 영어 문구가 더 길다. 영어 그림이 넘치기 쉬우니 짧게 다시 쓴다.
- `npm run check:layout -- <id> en/<id>`의 "그림 여유"가 음수면 넘친 글자가 바로 아래 줄에 나온다. 문구를 줄이거나 카드를 키운다.
- 캡션은 그림에서 먼저 볼 곳을 짚는 사실 한 줄이다. 경구나 반전("~하자는 말이 아니다")으로 쓰지 않는다.
