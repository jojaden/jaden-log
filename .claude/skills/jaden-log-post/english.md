# 영어판

기본 규칙은 저장소 `CLAUDE.md`의 "영어판"에 있다. 같은 번호 파일, 다시 쓴 영어, 한국어 그대로인 카테고리, 영어 태그, 영어 그림, 같은 언어 링크, 따로 고르는 표지가 그것이다. 여기는 거기에 더할 것만 적는다.

## 다시 쓰기

- 한국어판과 같은 내용, 같은 구조(h2 수, 그림, 실습, 표)를 영어 문장으로 다시 쓴다. 한국어 어순을 따라가지 않는다.
- 기술 글 제목은 `[식별자·개념] — [훅]` 꼴로 쓰고, 영어 독자가 검색할 말을 앞에 둔다. 예: `Copying structs in Go — why a shallow copy changes the map too`. 회고와 단상은 평서문이나 질문으로, sentence case로 쓴다.
- 코드 주석, 출력에 찍히는 라벨, 테스트 이름, 카드 제목(`title`)도 영어로 바꾼다.
  - 출력 글자가 바뀌었으면 바뀐 코드를 다시 돌려 출력을 확인한다. 줄 번호(`main_test.go:29`)가 같은지도 본다.
- 한국 독자만 아는 맥락(한국 서비스 이름, 한국어 검색 이야기)은 풀어 쓰거나 뺀다.
- 링크는 영어판이 있는 글만 `/en/<id>`로 건다. 영어판이 없으면 링크를 걸지 않는다.

## 영어 말투

한국어판 [voice.md](voice.md)의 기준을 영어에도 똑같이 적용한다. 영어에서 자주 나오는 꼴은 이렇다.

| 쓰지 않는다 | 대신 |
| --- | --- |
| `X isn't A; it's B`, `not A but B`, `A, not B`를 되풀이한다 | 글의 주제문 한두 번만 남긴다. 나머지는 사실로 쓴다 |
| 문단 끝의 경구(`The code won't say it for you.`, `If it does, you've understood it.`) | 지우거나, 마지막 사실과 다음에 한 일로 바꾼다 |
| 요약형 머리말(`In short`, `Put simply`, `The answer is simple`) | 머리말 없이 답을 바로 쓴다 |
| 굵은 머리말 목록(`- **defer: …, not …**`) | 식별자 칩이나 일반 문장으로 시작하고, 항목마다 모양을 다르게 한다 |
| 대시 `—`로 잇는 문장 | 문장을 나누거나 쉼표, 세미콜론, 괄호를 쓴다 |

인칭과 문장은 이렇게 쓴다.

- **인칭.**
  - 겪은 일은 `I`로 쓴다. 한국어판에 넣은 착각 문장은 영어판에도 같은 뜻으로 넣는다.
  - 개념이나 코드를 독자와 함께 따라가는 대목은 `we`/`let's`로 쓴다(Josh Comeau, Bartosz Ciechanowski, Go 블로그).
  - 조언하는 단상에서만 `you`를 쓴다.
- **답을 앞에.**
  - 셋째 문단 안에 짧은 답을 한 문장으로 둔다. 예: `The short answer is that …`.
  - 장애를 다룬 글은 둘째 문단에 무엇이 원인이었는지를 둔다(Cloudflare 장애 회고).
- **모르는 것.** 모르는 건 그대로 쓴다. 예: `I don't know whether …`, `It's possible I've made some mistakes here`, `This turned out to be a coincidence`.
- **닫는 말.** 요약 대신 행동이나 초대로 닫는다. 예: `If you try this, I'd like to hear how it goes.`, `Corrections welcome.` 같은 문장을 쓰거나, 다음에 할 일을 쓴다.
- **문장 길이.** 짧은 문장을 섞는다. 회고 글에서 6단어 이하 문장이 다섯에 하나쯤 되면 읽기 편하다(Dan Abramov).
- **대시.** 천 단어당 3개 이하로 쓴다. 인기 글 실측은 0~2.7개였고, 에세이는 2~4개였다.
- **인용.** 한국어 자료를 인용하면 내가 옮긴 말 뒤에 `(translated)`를 붙이고 원문 링크를 단다. 영어 자료는 원문 그대로 인용한다.
- **고친 내용.** 발행 뒤에 결론이 바뀌는 수정은 `## Updates` 절에 날짜와 함께 남긴다.

`npm run check:voice -- en/<id>`로 대시, 반전, 경구, 같은 박자를 센다. 영어는 문장 길이 표준편차 기준을 두지 않는다.

## 그림

- 영어 SVG는 한국어판과 같은 생성기로 같은 배치에서 뽑는다. 영어 문구는 더 길어서 폭 390에서 넘치기 쉽다. 카드를 키우지 말고 문구를 짧게 다시 쓴다.
- 캡션과 `aria-label`도 영어로 쓴다. `aria-label`에는 `"`를 넣지 않는다.

## 검사

- `npm run check:title -- en/<id>`
- `npm run check:voice -- en/<id>`
- `npm run check:layout -- en/<id>`
- `npm run cover -- en/<id>`
- 시리즈에 넣었다면 `series.ts`의 영어 이름도 채운다. 영어판이 없는 편은 영어 목록에서 저절로 빠진다.
